## 📋 Sobre o Projeto

BLACKBOX Dropper é uma ferramenta de pentest para criação de droppers de arquivos. 
O projeto foi adaptado e melhorado a partir do Umbrella Dropper, trazendo:

- ✅ Interface em Português-BR
- ✅ Suporte para Python 3
- ✅ Compatibilidade com Windows e Linux
- ✅ Novos recursos e melhorias
- ✅ Documentação atualizada
